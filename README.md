# HoNest (HN)

> We trust that you are honest.

A deliberately trust-based social network prototype. No passwords: users identify themselves by username.

## MVP
- Passwordless/trust-based login
- Account creation
- Profile: PFP, name, username, bio, banner URL
- Self-declared blue verification
- Text/image post feed
- Likes and unlikes
- Direct replies
- 10-minute post editing window
- Delete own posts
- Local persistence with `localStorage`
